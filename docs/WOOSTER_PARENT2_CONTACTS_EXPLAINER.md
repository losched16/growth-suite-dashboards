# For Wooster: why you'll start seeing "Parent 2" contacts in Growth Suite

**Short version:** each family is still ONE record — the Parent 1 contact. When a second parent has an email on file, Growth Suite now also creates a small linked contact for them so we can actually email them (portal invites, form reminders, school announcements). Those extra contacts are tagged **Parent 2** and are communication-only. Nothing about your students or forms moves.

## What you'll see

- New contacts named for the second parent (e.g. "Beth Zsoldos"), tagged **Parent 2** and **Parent**, linked to the family's main contact as a *co-parent* relationship.
- The main contact gets a **Parent 1** tag.
- Your contact count goes up by one per family that has a second parent with an email. Today that's 12; as you add Parent 2 emails it can grow to roughly one per two-parent family (~120). GHL doesn't charge per contact, so there's no cost.

## The rules (this is the part that avoids confusion)

| | Parent 1 contact | Parent 2 contact |
|---|---|---|
| What it is | **The family record.** Students, enrollment status, programs, forms tracking, tuition — all live here. | A mailbox. Name, email, phone only. |
| Put student info here? | Yes — only here. | **No.** Never add students to a Parent 2 contact. |
| Shows on dashboards as a family? | Yes | No — it is *not* a second family |
| Gets emails? | Yes | Yes (that's the whole point) |
| Tags | Yours to manage | Mirrored automatically from Parent 1 (e.g. "enrolled - 26/27") so school-wide emails reach both parents |
| Pipeline card | Yes | No |

## How to add a second parent (the right way)

Any of these work — they all end up in the same place:

1. **In GHL:** on the Parent 1 contact, fill **Parent 2 First Name / Last Name / Email** (and phone). Within 15 minutes the co-parent appears on the family and can sign in at portal.woomontessori.org by entering their email and creating a password. No invite link needed.
2. **In the parent portal:** the first parent uses **"Add another parent."** Same result; an invite email goes out.
3. Either way, the linked Parent 2 contact is created for you automatically (nightly). Don't create it by hand.

## Please don't

- **Don't delete** a Parent 2 contact — the second parent loses their email path (the family itself is unaffected).
- **Don't merge** a Parent 2 contact into the Parent 1 contact.
- **Don't add students** or change enrollment status on a Parent 2 contact — dashboards only read the Parent 1 record.
- **Don't create a separate full contact for a second parent with the kids re-listed** — that's the pattern that was making duplicate families (Dunlap, Welsh, Wachtel).

## Counting and smart lists

- Counting *families*: filter on the **Parent 1** tag (or use the Family Hub dashboard — 159 families).
- Emailing *everyone*: use the "enrolled - 26/27" tag as you do today — it now reaches both parents.
- Why you might see a parent twice in a list: once as the family record, once as the mailbox. That's expected.
